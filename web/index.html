Bring your exports

Export one flow from Dorico. Add its MusicXML to account for bars and system breaks.

How to export from Dorico
  1. Use File → Export → MIDI for the flow containing your CC automation.
  2. Use File → Export → MusicXML. Export the same flow and the actual destination layout—full score or performer’s part.
  3. Keep both exports on the same written timeline. MIDI playback repeats may otherwise shift the alignment.

MusicXML records this layout’s breaks. Export it again after reflowing the score.

Copying into an existing score

Prepare equivalent hidden guide notes on a pitched controller staff. Filter and copy the horizontal lines, then paste at the same musical position. The kit gives the precise starting beat.

System corrections belong to the exported destination layout. If its breaks change, regenerate for that layout and replace the old contour.

Native objects. Musical anchors.

Smoothing is sampled into connected straight lines. Each segment stays attached to rhythmic positions, so meter changes do not change its timing. Guide notes remain as hidden anchors.

A tested experiment, still evolving.

Tested with Dorico 5.1.81 on macOS. Supports MIDI 0/1, PPQN and 7-bit CC. One flow at a time; tuplets, mid-bar breaks and other Dorico versions need further testing. This creates notation, not MIDI playback.
